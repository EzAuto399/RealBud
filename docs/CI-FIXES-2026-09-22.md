# CI fixes, 22 September 2026

Two red suites on Node 24 (macOS and Ubuntu runners). Both were test-side; no product change.

## 1. manual-job-request overlap test failed everywhere

Cause. `c9d43dbe` added two optional awaits to `executeRecipeJob` before the worker call:
`await dependencies.instructionContext?.(…)` and `await department?.check()`. Both are no-ops when the
dependency is absent, but each still burns a microtask tick, so the first attempt no longer reached
`ask` before the duplicate request's `await` resolved. The test asserted `calls === 1` at that exact
tick, so it read 0 and `release` was still unassigned.

Fix. `server/manual-job-request.test.ts` now waits on a promise the fake worker resolves on entry,
instead of assuming a microtask count. The duplicate is still issued before the worker starts, and
`calls === 1` is still asserted — the assertion was moved, not weakened.

Not a defect. `enqueue` is synchronous and enqueue-first; a duplicate key returns `created: false`
without re-running. Evidence: reverting only `server/job-executor.ts` to `HEAD~2` makes the test pass.

## 2. private-backup-restore-catalog bulk test timed out on Ubuntu

Cause. 5,101 encrypted SQLite inserts across two catalogs plus the read-back, against a slow shared
runner disk. No quadratic step: `addRecord`/`iterateRecords` are indexed, O(log n) per row.

Fix. That test's explicit budget is now `BULK_TIMEOUT_MS` — 120 s when `process.env.CI` is set, 30 s
locally. The other two 30 s tests in the file are unchanged.
