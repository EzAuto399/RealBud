## What changed

1. **REI Cloud recipe runner** (`server/portal-recipe-runner.ts`, `server/portal-recipe-task.ts`, Austin pack `recipes.json`). Known read recipes replay through the real BrowserBroker with no model call per click. Pack-declared read-safe controls relax the bank-page rule only on the declared origin, inside the declared pager landmark (page numbers or page size required), with no consequential control in scope or open dialog. The account marker must match the banner exactly. The live REI pager landmark is `null` until a read-only live look, so live paging asks. Four independent review rounds; remaining accepted residual: a real pager beside a sibling region holding a consequential button.
2. **Electron 43.7.5, BrowserSkill 0.3.1** (checksums verified against the GitHub release). A same-protocol, same-minor extension is accepted so a store update does not break the browser.
3. **Provisioning.** Lost desktop or website replies and a slow gateway are reconciled on the next check-in with one mint and the undelivered key revoked. `REALBUD_MODELVIA_MODELS` has no default and rejects `auto` (an allowlist of `auto` admitted no model in Modelvia). The gateway refuses a customer not bound to the office. Per-office-billed customers are created with `billingCompanyId = companyId` (assumption to confirm). Composio stays one project and `ak_` per office; each computer has its own `rbc_` credential and Composio user.
4. **Installed app.** Quit completes with `app.exit(0)` (Electron ignores a second `app.quit()` after a prevented `will-quit`). Desk writes roll back on a failed save. Startup shows the specific cause (data folder, disk full, ports). More menu dismisses. Duplicate error sentence removed.
5. **Windows.** Backup privacy checks run as one async PowerShell batch per pass instead of one per path. First-run read gives up after 20 s with Try again; a blank window reloads on second launch. The watchdog needs three failed probes over 45 s and adopts a busy port that answers with our identity.
