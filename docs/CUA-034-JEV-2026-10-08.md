## What changed

- **cua-driver 0.19.3 → 0.34.0.** Pins and sha256 for macOS, Windows and the
  container wheels; Windows host contract 0.8.0. `click` now takes only a fresh
  `element_token`. Never-allowed tools in every turn: `install_extension`,
  `parse_visual_regions` (OmniParser, AGPL), `install_ffmpeg`, `set_config`,
  `check_for_update` (`server/cua-bounded.ts`, `server/drivers/acp/core.ts`).
- **Jev batching.** W1 payer hints: 8 rows per call, 3 calls at once, a failed
  call loses only its rows. W3 noise screen: same packing, partial results kept.
- **Ledger columns.** Jev first (redacted header names only, skipped when row 0
  looks like data); Hermes turn unchanged as the fallback.
- **Ask pre-route** (`server/ask-jev-route.ts`). Person-typed Ask only; routes to
  five read-only existing replies; anything unsure goes to Bud. A bot waiting
  on Jev counts as busy, so a second message queues.
- **Duplicate bills.** Jev orders candidates and adds "Likely the same bill ·
  suggestion only". Holds and the review digest are unchanged; Save never calls
  Jev; ranking capped at 3 s and cached per review digest.
- **Bud `decide` tool** (`server/decide-broker.ts`). Person Ask turns only (one
  gate, `personAskTurn`). Refuses secret-named keys by whole word, confusable
  keys and one-time codes; 10 calls per turn.
- **Jev eval** (`scripts/eval-jev.mjs`, docs/QA-LIVE-DEBUG.md "Jev eval"). 190
  fictional cases over six uses; reports coverage, wrong-accepts and the
  threshold sweep. Only the fake arm has run.
