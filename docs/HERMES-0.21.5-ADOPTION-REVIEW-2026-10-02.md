- **BREAKING — memory proposal schema.** Upstream adds `matched_entry` to destructive proposals and refuses legacy replace/remove proposals lacking it. RealBud’s helper rejects this field, while its own proposals do not supply it. Repinning alone will not work. Preserve legacy records and require rejection/recreation rather than retargeting them. `U:tools/memory_tool.py:64,285` → `server/helpers/hermes-memory-review.py:36,780,817`, `server/helpers/hermes-memory-proposals.py`.
- **BREAKING — native memory admission.** RealBud admits only the 0.21.3 commit and eight module hashes; staged learning has a separate commit check. Upstream also introduces a `hermes_platform.host.runtime` import, so the reviewed import closure and native fixture need expansion. `U:hermes_constants.py:16` → `server/hermes-memory-review.ts:24,48,79`, `server/hermes-pack.ts:367`, `server/testing/native-memory-fixture.ts:15`.
- **RISK — ACP tool selection now respects configuration.** ACP previously hardcoded `hermes-acp`; it now honors `platform_toolsets.acp` and `agent.disabled_toolsets`. RealBud replaces top-level `toolsets` but preserves `platform_toolsets`. Own an explicit ACP selection and exclusions, including configured-MCP suppression, without removing explicitly mounted host brokers. `U:acp_adapter/session.py:480`, `U:hermes_cli/tools_config.py:576` → `server/hermes-pack.ts:258`, `pack/property/config.yaml`, `server/drivers/acp/hermes.ts`.
- **Migration can add connector tools.** Schema migration 44→45 appends `connections` to qualifying saved platform lists unless excluded or previously declined. Migration 45→46 translates MCP `disabled:true` to `enabled:false`; unversioned files follow a narrower migration set. Test both stamped and unstamped profiles. `U:hermes_cli/config_migrations.py:561,608,768` → `server/hermes-pack.ts`.
- **No ACP wire-version break identified.** `agent-client-protocol==0.9.0`, protocol constant, existing methods and permission outcomes remain. Session creation/restoration now runs off the event loop; cancellation reaches background delegations; conflicting reset/compress/model operations are serialized. Keep RealBud’s existing fresh-process transcript replay until separately qualified. `U:pyproject.toml:306`, `U:acp_adapter/server.py:526,609,1016`, `U:acp_adapter/session.py:167` → `server/drivers/acp/core.ts`, `hermes.ts`.
