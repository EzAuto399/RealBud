## Problem Statement

Austin Realty (Kevin finance, Danny principal) already runs REI Cloud. Pain is exceptions around it: wrong/missing rent references before Bulk Receipting, and expected owner bills (council / water / levy) that never arrive. They do not need another PMS. They need RealBud as a complete, onboardable product shell with first-party workflow packs so Kevin’s day gets clearer without him building automations — and so the next Mandarin / AU agency can be onboarded the same way.

## Demand Evidence

- Live interview (2026-09-10, ~52 min): Kevin demonstrated bank CSV → Bulk Receipting; unmatched reference UI visible.
- Kevin’s clearest ask: estimate when a bill should arrive; flag absence; mark received / in-process / paid without a second Excel register.
- Danny’s closing order: “REI and Bills first”; Excel/CRM classification later.
- No paid pilot yet. Strongest next demand signal = Danny paying a fit check.

## Status Quo

- Rent: bank export → manual CSV cleanup → REI Bulk Receipting (~every two days) → arrears / Form 11 judgment in REI.
- Bills: memory + email + attempted Excel register (duplicate of REI) → misses when providers change.
- Form 11: generated/sent in REI Cloud; pain is later evidence retrieval (deferred).
- Airbnb: 4–5 short-stay properties; batch payout split (Phase 1.5).
- Sales CRM: Excel / company-owned buyer list (Phase 2).

## Target User & Narrowest Wedge

- Primary operator: Kevin (accounts / rent / owner expenses).
- Buyer / sponsor: Danny.
- Wedge worth paying for: **expected-bill calendar on Desk (100–200 properties, grouped) + payment-reference exception prep** before REI. Inbox only as evidence feeder, not a third hero.

## Constraints

- RealBud owns clock, Desk, packs, Continue/Stop, receipts. Hermes = hands via pinned `property` pack. No Hermes.app, no second cron.
- Windows 11 acceptance required for live bank/REI routes; Mac packaging ≠ acceptance.
- Prepare-only: no pay / import authority / send without explicit human approval paths.
- Founding price is a concession (family-friend + first Mandarin customer), not the list price for referrals.
- **Founding project fee locked: A$5,500 Stage 1 Agent OS** + **A$299/month** care; **first two care months included** (month 1 training, month 2 monitoring; retainer from month 3). **Stage 2 CRM separate at A$2,000** + **A$149/month**.

## Premises

1. Sellable unit = Desk + clock + versioned packs (not “Hermes for property”).
2. Austin Phase 1 = bills calendar + payment prep; inbox thin; Form 11 evidence and Airbnb after main workflows prove out; CRM = Phase 2.
3. Custom office work = agency config + pack revision, not a product fork.
4. A$5–7k only works with this narrow Phase 1 and real Windows acceptance.

### Computer-use → workflow (how Hermes becomes a pack)

Computer use is **not** the workflow. RealBud owns the job; Hermes/Cua only run **allowed steps** when a step needs hands on Gmail/bank/REI.

```text
Schedule (RealBud clock)
  → JobRun / pack step (typed: read mail | link bill | hold exception)
  → if needs desktop: attended lease + Hermes hands inside fence
  → result written to Desk (property bill calendar / payment queue)
  → Kevin decides; Bud never pays
```

**Bills pack states (from interview):** expected → missing → received → in-process → paid; plus exceptions: insufficient owner funds → company advance (loaned, recover later) → owner-to-pay (large levy) → hold/unknown.

**Do not** “every day free-form browse Gmail.” Do: daily bounded mailbox read → match to expected-bill register → update Desk under the property → flag exceptions for Kevin.
