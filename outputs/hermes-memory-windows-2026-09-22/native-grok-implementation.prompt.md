- CreateFileW: https://learn.microsoft.com/en-us/windows/win32/api/fileapi/nf-fileapi-createfilew . CREATE_NEW fails if file exists, OPEN_EXISTING never creates; never CREATE_ALWAYS/TRUNCATE_EXISTING. Explicit SECURITY_ATTRIBUTES installs security before creating object; ignored for existing object. bInheritHandle FALSE. FILE_FLAG_OPEN_REPARSE_POINT opens the leaf reparse point itself; refuse it by handle attributes. FILE_FLAG_BACKUP_SEMANTICS required for directory handles. Exclude FILE_SHARE_DELETE to pin against rename/delete. This does NOT by itself protect ancestor paths; caller owns ancestor pins. For files use FILE_SHARE_READ only (exclude WRITE); directory metadata handle may use FILE_SHARE_READ|FILE_SHARE_WRITE but never DELETE, and caller rechecks/pins ancestors.
- GetSecurityInfo https://learn.microsoft.com/en-us/windows/win32/api/aclapi/nf-aclapi-getsecurityinfo retrieves security descriptor by actual handle. Request OWNER_SECURITY_INFORMATION|DACL_SECURITY_INFORMATION on SE_FILE_OBJECT, with READ_CONTROL requested when opening. Returned owner/DACL pointers live within returned SD. LocalFree the SD in finally. Concurrent descriptor changes can fail; no fallback to path Get-Acl.
- GetSecurityDescriptorControl https://learn.microsoft.com/en-us/windows/win32/api/securitybaseapi/nf-securitybaseapi-getsecuritydescriptorcontrol returns SE_DACL_PRESENT, SE_DACL_PROTECTED. Validate security descriptor/ACL with IsValidSecurityDescriptor/IsValidAcl. Null/absent DACL forbidden.
- GetAce https://learn.microsoft.com/en-us/windows/win32/api/securitybaseapi/nf-securitybaseapi-getace yields ACE_HEADER; bound count/size and use only ACCESS_ALLOWED_ACE_TYPE(0), deny/unknown/object/callback ACE types rejected conservatively. SID is at offset8 in simple ACCESS_ALLOWED_ACE after header+mask; validate IsValidSid/GetLengthSid within AceSize before convert/copy. Do not dereference an unbounded fabricated pointer; GetAce pointer range must lie within ACL and ACE must fit it. A bounded ACL memory copy may simplify validation. Never print SID.
- GetFileInformationByHandle https://learn.microsoft.com/en-us/windows/win32/api/fileapi/nf-fileapi-getfileinformationbyhandle provides volume serial + file index identity; combine index high/low as 64-bit, no zero/unknown identity. Directory has directory attribute; requested kind must match. GetFileType must FILE_TYPE_DISK.
- GetFinalPathNameByHandleW https://learn.microsoft.com/en-us/windows/win32/api/fileapi/nf-fileapi-getfinalpathnamebyhandlew with FILE_NAME_NORMALIZED|VOLUME_NAME_DOS returns extended DOS path. Allocate/retry a bounded WCHAR buffer (<32768) with careful returned count incl/excl terminator semantics. Refuse UNC/device/nondrive final paths. Normalize only normal DOS/extended DOS drive paths. Initial strict case-preserving component match is acceptable; normalize drive case. Reject colon ADS, relative path, '.', '..', trailing dot/space, reserved DOS device components, embedded NUL/control, raw device namespaces, unsupported separator ambiguity. - GetVolumeInformationByHandleW https://learn.microsoft.com/en-us/windows/win32/api/fileapi/nf-fileapi-getvolumeinformationbyhandlew plus GetDriveTypeW: admit only NTFS, FILE_PERSISTENT_ACLS, DRIVE_FIXED, same volume serial as file identity. No ReFS/SMB/FAT/sync/removable support claim. Disk sync/reparse providers are refused by attributes; detection of arbitrary synchronizer is outside scope.
- GetTokenInformation https://learn.microsoft.com/en-us/windows/win32/api/securitybaseapi/nf-securitybaseapi-gettokeninformation: OpenProcessToken(GetCurrentProcess(),TOKEN_QUERY), bounded two-pass TokenUser info, SID validate/convert using ConvertSidToStringSidW/LocalFree, CloseHandle token. All failures fixed errors.

Privacy policy: same conservative SID allowlist as existing global verifier: current token user, S-1-5-18(SYSTEM), S-1-5-32-544(Admins); allowed owner must one of those. Current-user effective non-INHERIT_ONLY allow ACE(s) must cover FILE_ALL_ACCESS (0x001F01FF). Require nonnull present DACL. Refuse ANY deny or unknown ACE; refuse all allow ACEs for other SIDs even inherit-only (conservative existing policy). Accept simple allow flags only valid inheritance flags. Account all actual ACE masks (generic bits map to file read/write/execute/all masks before comparing), not ACL labels. Protected DACL normally mandatory. Optional inherited child admission only with a live Handle private_root that is a directory, protected, independently passes the same ACL policy without recursively allowing inheritance, same-volume strict descendant path; verify child's actual ACEs too. This is a separate local admission method, do not change global Windows policy. Reverify privacy on each read/write/flush, using stored verified root if inherited admission explicitly established, and snapshots before/after to detect drift. A new object must use protected mode, never inherited exception. No data read/write if verification failed. Bound read/write <=128KiB: reject booleans/non-int/negative/too-large limit, nonbytes/too-large writes. read starts at0, requests at most limit+1 and fails capacity if data larger, uses snapshots/stable attrs+identity+size/mtime around read. write only on newly created file Handle (foundation does not permit overwriting existing native memory); must be first write into zero-size object, mark attempted BEFORE first native write; partial/failed write prevents retrying/reusing that handle to write. Loop short writes, zero progress failure, writes completed must match expected size and identity; no truncate. Flush explicit, never silently ignore failures. The caller will handle retries and atomic replacement later.
