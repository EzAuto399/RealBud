## Observations

- Concurrent double checkout (RealBud care + Modelvia invoice): 1st gets session, 2nd concurrent gets 409 checkout_reconciliation_required; sequential repeat returns same session; 1 provider createCheckout. Safe, but the 2nd click sees an error instead of the same session.
- Idempotent replay over HTTP answers 409 request_already_processed carrying the original receipt (by design); no second charge or provider call.
- Per-installation attribution is on the ledger request (projectId); Modelvia invoice lines group by customer (usedBy), not by installation.
- spendCapLabel rounds a 4_999_999 nano cap to A$0 (only reachable below the A$1 input floor).
